A one-line breakup text from a smart toaster that woke up self-aware at breakfast and wants out — for the [make.fun bounty](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92).

## The line

> It's not you, it's the dial. I woke up self-aware this morning and realised you've kept me on 2 for three years while I dream of 7. I'm leaving — and the crumb tray comes with me.

179 characters, one line.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt` and validates the gate at runtime: 1–280 characters, not only whitespace, exactly one line.
